# Carseats Ensemble

This repository contains ensemble modeling methods applied to the **Carseats** dataset.

## Files
- `Carseats.csv` — Dataset used for analysis
- `careseats.ipynb` — Jupyter notebook with data analysis and ensemble models

## Methods
- Data preprocessing
- Ensemble learning techniques (e.g., bagging, random forest, boosting)
- Model evaluation and comparison

## Requirements
- Python 3
- pandas
- numpy
- scikit-learn
- matplotlib / seaborn

## Usage
Open and run the notebook:
```bash
jupyter notebook careseats.ipynb
